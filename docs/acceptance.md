## 交付边界

- 容量测试使用真实本地 HTTP 目标和 webhook，不能推导远端慢服务、慢通知商或完整 14 天原始历史下的吞吐上限。
- Beszel 实测基线为 0.20.0，仅接纳 0.20.x；真实 Hub 历史与容器使用种子样本，验证协议和展示，不表示已压测其 agent 采集。
- 外部通知允许极端情况下重复发送；数据库持久任务和恢复标记保证平台的有限重试与有效性，不保证外部系统 exactly-once。
- 独立域名绑定由平台完成，DNS 和 HTTPS 由部署环境提供。
- SQLite CLI backup 也取得实例锁，须停服务后运行；数据库、原密钥和图片缺一会影响完整恢复。
- 首版阶段记录了临时 Compose 容器/网络/卷、Colima octopulse-test、专用 PostgreSQL cluster、demo 与 Beszel fixture 的清理。本轮未核查这些进程和环境的当前状态。

- 当前没有分布式探针、多实例调度、GitHub 主题、公开注册、OIDC、受保护状态页或数据库互转工具；这些均不在已确认首版内。
