# 状态页发布与汇总规则

状态：Q23 已确认，Q24 已按用户修正；最新范围调整移除首版 GitHub 主题，采用内置可配置 Vue CSR 页面。

## 状态页自定义配置

每页独立配置页面名称、标题、描述、Logo、公开链接、品牌色、浅色/深色、监控项公开别名、分组及排序。内置界面展示服务状态、可用率及覆盖率、延迟趋势、人工故障公告与维护信息；证书风险独立展示。

| 配置维度 | 首版范围 |
| --- | --- |
| 品牌 | 标题、描述、Logo、品牌色、公开链接、深浅色设置 |
| 服务展示 | 明确选择公开的监控项、独立公开别名、分组与组内排序 |
| 状态及指标 | 已确认的总状态规则、可用率/覆盖率、延迟趋势、独立证书风险 |
| 运维内容 | 人工公告、事件进展、计划维护及影响等级 |
| 发布入口 | 唯一 slug、路径访问、可选独立域名绑定 |

拟采用的编辑体验是以相同内置组件预览当前自定义配置、保存草稿并显式发布，公开访问读取已发布配置；桌面与移动布局均验证。页面样式通过结构化配置只作用于该页面，后台布局与视觉设置独立。

## 自动总状态

只汇总本页面明确发布的服务可用性监控项：HTTP(S)、TCP、DNS、被动心跳。暂停项不参与汇总，维护项以维护状态呈现。证书风险和 Beszel 指标不参与服务状态汇总。

按下表顺序判定；“全部”指所有已发布、未暂停的服务可用性监控项，必须至少有一项。

| 条件 | 自动总状态 |
| --- | --- |
| 全部为 Down | 全面故障 |
| 存在 Down，其他项为 Up、Unknown 或维护 | 部分故障 |
| 没有 Down，但存在 Unknown | 数据不足 |
| 没有 Down/Unknown，但存在维护项 | 维护 |
| 至少有一项且全部为 Up | 正常 |
| 没有服务可用性监控项，或全部暂停 | 数据不足 |

各项原始状态和维护范围继续单独显示，总状态不能遮盖局部信息。仅有证书监控的页面显示证书信息，服务总状态为数据不足。

## 人工公告

公告包含进展状态与显式影响等级，两者分开。活动公告可提升页面总影响等级为部分故障或全面故障，但不能降低自动发现的故障；页面标注人工公告来源。公告不会改写监控项状态或服务可用率。

没有影响等级的公告只展示内容。事件关闭后不再提升页面总状态。

## 公共字段与页面界面

公开数据仅包含明确发布的名称/别名、分组、服务状态、可用率/覆盖率、延迟趋势、证书风险、公开公告、维护信息和页面品牌设置。原始目标 URL、IP、请求头/正文、凭据及详细内部错误不直接暴露；公开链接由页面配置显式填写。

自定义只作用于对应的公开状态页，管理后台保持固定界面。每页首版支持独立路径和可选独立域名，例如 `https://example.com/status1` 与 `https://status1.example.com/`；每页域名绑定不延期。

平台按页面标识读取已发布的自定义配置及公共数据，两种入口共用同一内置页面组件，不引入外部代码或主题产物。

## 路由与部署责任

每页具有唯一 slug 和可选域名绑定。路径入口为 `/{slug}`；已绑定域名的根路径指向对应页面。后台/API/资源等保留路径不能用作 slug。路径与域名入口均支持该页面的合法公开子路由，前端资源地址与公共 API 地址独立于浏览器访问入口。

独立域名使用 DNS A/AAAA 或 CNAME 指向部署入口，反向代理提供覆盖该域名的 HTTPS 并保留 Host 转发到同一个 Go 服务。平台维护精确的 `hostname → page` 绑定；首版不内置 DNS 修改或自动申请证书，提供部署指引。

## 首版运行与权限

公开页面直接由平台内置 Vue CSR 界面渲染，不使用主题 iframe、消息桥或主题 SDK。管理接口继续独立执行会话、角色与 CSRF 校验，匿名公共 API 只返回已发布数据。GitHub 主题相关历史决定已由 [ADR 0011](./adr/0011-built-in-configurable-status-pages.md) 取代。
