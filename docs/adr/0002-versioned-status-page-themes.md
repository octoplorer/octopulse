# GitHub 主题完整定义状态页界面

2026-10-01：用户决定从首版移除 GitHub 主题，改为内置可配置状态页，见 [ADR 0011](./0011-built-in-configurable-status-pages.md)。以下保留过去设计背景，不再构成首版要求。

状态页主题可以完整替换界面并执行自定义浏览器 JavaScript，而不局限于预定义模块和样式调整。主题通过版本化的公共数据契约获取状态；首版使用明确可信且固定版本的 GitHub 主题仓库。

完整界面替换带来更大的定制自由，也使公共契约的稳定性成为兼容性要求。构建产物安装、预览与回滚已由 [ADR 0007](./0007-prebuilt-theme-packages.md) 确认；公共字段白名单及包含版本、入口、兼容范围和配置 schema 的主题包契约已接受。浏览器运行边界由 Q27 定稿。

主题只影响所发布的状态页，后台不受主题影响。每页首版同时支持默认路径和可选独立域名入口。
