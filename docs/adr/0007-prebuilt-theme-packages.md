# 安装预构建的状态页主题包

2026-10-01：主题包功能随 GitHub 主题一起移出首版，见 [ADR 0011](./0011-built-in-configurable-status-pages.md)。以下保留过去设计背景，不再构成首版要求。

GitHub 主题仓库在本地或 CI 中构建并发布版本化主题包，平台安装构建产物并支持预览与回滚。平台后台不执行主题仓库的构建脚本，这使生产服务保持 Go 运行边界，同时允许主题作者自行管理 Node.js 构建依赖。

主题包声明版本、入口、公共契约兼容范围与配置 schema，主题仅获取明确发布的公共字段；浏览器运行方式由 Q27 定稿。预构建不改变主题可以运行自定义浏览器 JavaScript 的既定能力。
